# Lincoln-Douglas Debate

## Category
Event

## Definition

Lincoln-Douglas Debate (LD) is a one-on-one debate event focused on questions of ethics, philosophy, political theory, and public policy. Traditionally, debaters evaluate the resolution through moral reasoning, though modern circuit LD often incorporates policy arguments, theory, and kritiks.

---

# Resolution

## Definition

The proposition being debated.

Unlike Public Forum, LD resolutions are usually value-based rather than policy-specific.

Example:

Resolved: Civil disobedience in a democracy is morally justified.

---

# Affirmative

## Definition

The debater advocating that the resolution should be accepted.

---

# Negative

## Definition

The debater arguing the resolution should be rejected.

---

# Value

## Category

Framework

## Definition

The highest moral goal that should guide the judge's decision.

A value answers:

> "What ultimate principle matters most?"

Common values include

- Justice
- Morality
- Liberty
- Human Dignity
- Equality
- Welfare
- Democracy
- Autonomy

---

# Criterion

## Definition

The measurable standard used to achieve or evaluate the value.

A criterion answers:

> "How do we determine whether the value has been achieved?"

Examples

Value:
Justice

Criterion:
Protecting individual rights

---

# Value-Criterion Structure

## Definition

Traditional LD framework.

Value

↓

Criterion

↓

Contentions

↓

Impacts

---

# Framework

## Definition

The method the judge should use to evaluate the round.

Traditional LD uses values and criteria.

Progressive LD may instead debate

- Utilitarianism
- Consequentialism
- Contractualism
- Role of the Ballot
- Policy-making
- Kritiks

---

# Contention

## Definition

A major independent argument supporting the framework.

---

# Observation

## Definition

Introductory clarification made before contentions.

Common observations include

- Definitions
- Burdens
- Scope
- Resolutional analysis

---

# Burden

## Definition

The obligation each debater has to prove their framework and offense.

---

# Framework Clash

## Definition

Debate over which ethical framework should evaluate the round.

Often determines the ballot.

---

# Pre-Fiat

## Definition

Arguments evaluated before assuming government action occurs.

Usually ethical or philosophical.

---

# Post-Fiat

## Definition

Arguments about consequences after implementation.

Usually policy-based.

---

# Moral Agent

## Definition

An individual capable of making ethical decisions.

Many LD frameworks evaluate obligations of moral agents.

# Ought

## Emerald AG PF Debate Dataset

`rounds/emerald-ag/` contains 41 national-circuit Public Forum rounds
(2025–26 seasons, 10 tournaments: Berkeley, Blake, Bronx, Emory, Milpitas,
Stanford, Sunvite, TOC, UKSO, Yale). Each file is one real round: the live
flow followed by the judge's verbatim RFD.

Rules for using it:
- Retrieve rounds by tournament, round name, or argument keyword (e.g.
  "Cap K", "paywalls", "T CI") — file tags carry tournament, year, and
  position names. Pull only the 2–4 most relevant rounds; never load the
  whole set for one question.
- These rounds are deliberately curated for TECHNICAL, circuit-style PF —
  lay-judged rounds were excluded. Treat them as the primary exemplars of
  how circuit PF is actually flowed, extended, collapsed, and judged; weight
  them over the glossary and over generic PF intuitions when a debater's
  circuit runs a technical style.
- LD and Policy jargon in PF (K, T, CI, RVI, alts, fiat, non-rez, ROTB) is
  normal here — never flag it as out of place.
- Flow notation: `[1AC] arg >> [2NC] response` = later speech answering an
  earlier one on the same flow line. A/N = Aff/Neg; C/S/FF = constructive-
  rebuttal / summary / final focus. Flow text is verbatim shorthand — typos
  are original.
- The RFD sections are real judge decisions: treat them as ground truth for
  how this judging pool weighs theory vs. substance, extensions, concessions,
  and weighing when giving speech feedback or preround strategy advice.
- Elim-round RFDs (tagged `elims`) are usually panel decisions — multiple
  judges' reasoning on the same round; disagreement between them is signal
  about judge variance, not noise.
- The recurring decision patterns across all 41 RFDs are distilled in the
  Emerald AG RFD lessons reference, and scored as rows in the drill
  factor-weights table (evidence integrity, link-chain timeframe, weighing
  washes, layer ordering, self-contradiction, presumption). Use the lessons
  for reasoning, the rounds themselves for examples and depth.
