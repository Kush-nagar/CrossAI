EternalBlue was first developed by the NSA and later spread by hacker group Shadow
BrokersThe NSA discovered a Windows security vulnerability and created the EternalBlue
exploit, which was then stolen and leaked by the hacker group Shadow Brokers. On March 14,
2017, exactly one month before the Shadow Brokers leak, Microsoft released Security Bulletin
MS17-010. The timeline suggests that Microsoft was tipped off about the NSA breach and

rushed to do all they could to protect the millions of vulnerable Windows systems. The
MS17-010 patch was designed to fix the SMBv1 software flaws for all supported Windows
operating systems, including Windows Vista, Windows 7, Windows 8.1, Windows 10, Windows
Server 2008, Windows Server 2012, and Windows Server 2016. Microsoft also automatically
disabled SMBv1 in the latest versions of Windows 10 and Windows Servers 2012 and 2016 by
default. Additionally, in an unprecedented move to demonstrate the severity of the EternalBlue
exploit, Microsoft released a second emergency patch for unsupported operating systems once
the leak was made public. This second release supported Windows XP, Windows 8, and
Windows Server 2003. How does EternalBlue work? The EternalBlue exploit works by taking
advantage of SMBv1 vulnerabilities present in older versions of Microsoft operating systems.
SMBv1 was first developed in early 1983 as a network communication protocol to enable
shared access to files, printers, and ports. It was essentially a way for Windows machines to talk
to one another and other devices for remote services. EternalBlue takes advantage of SMBv1
vulnerabilities.EternalBlue exploits SMBv1 vulnerabilities to insert malicious data packets and
spread malware over the network. The exploit makes use of the way Microsoft Windows
handles, or rather mishandles, specially crafted packets from malicious attackers. All the
attacker needs to do is send a maliciously-crafted packet to the target server, and, boom, the
malware propagates and a cyberattack ensues. EternalBlue's Common Vulnerabilities and
Exposures number is logged in the National Vulnerability Database as CVE-2017-0144.
Microsoft’s patch closes the security vulnerability completely, thus preventing attempts at
deploying ransomware, malware, cryptojacking, or any other worm-like attempts at digital

Windows, the software update must be installed in order to provide protection It is this key
problem that gives EternalBlue such a long shelf life — many people and even businesses fail
to update their software regularly, leaving their operating systems unpatched and thus
vulnerable to EternalBlue and other attacks. To this day, the number of unpatched vulnerable
Windows systems remains in the millions. How is EternalBlue used in cyberattacks?

## Construction-criteria audit

### Embedded weighing
ABSENT: The document contains no explicit weighing mechanisms—no magnitude, probability, timeframe, or scope comparisons between impacts, and no pre-written "even if" or "outweighs" language. Cards are presented as standalone evidence dumps rather than calibrated for comparative impact calculus. A card filling this gap would carry a tag like "Encryption backdoors cause billions in annual economic damage — outweighs speculative law enforcement access" (citing Cybersecurity Ventures 2025 $10.5T figure + JP Morgan 45B daily attempts) and belong in a dedicated weighing block after Contention 1 evidence.

### Offensive spikes
ABSENT: No cards preempt or interact with likely Pro positions (e.g., "encryption enables child exploitation," "law enforcement needs access for terrorism investigations," "warrant-proof spaces"). The case reads as purely defensive—documenting harms of backdoors without anticipating and undercutting the affirmative's core justifications. An offensive spike would be a card tagged "Law enforcement already accesses 90%+ of digital evidence without breaking encryption — backdoors unnecessary" (citing DOJ/NSA transparency reports or Carnegie Endowment 2023) placed early to neuter Pro's necessity argument.

### Defensive spikes
**Matt Olsen et. al, 16, Harvard** — "Adding backdoors will only exacerbate the risks... If the FBI can eavesdrop on your text messages or get at your computer's hard drive, so can other governments. So can criminals. So can terrorists." This functions as a preemptive frontline against the "authorized access only" / "secure golden key" Pro argument by warranting that any technical backdoor is inevitably exploitable by adversaries, citing historical examples (Vodafone/Greece, Google/CALEA/China breach).

### Evidence quality
**Maureen Stanton, 25, Boston University** — "Our Online World Relies on Encryption. What Happens If It Fails?" (June 2, 2025). Recency is excellent (2025), author is affiliated with a major research university, and the card cites concrete, verifiable data (JP Morgan: 45 billion hacking attempts/day). However, most other cards are significantly dated (Olsen 2016, Zetter 2015, Avast 2020, Cybersecurity Ventures 2020 projection), and several sources are advocacy organizations (EFF, Avast) or journalistic outlets (WIRED, Forbes) rather than peer-reviewed or government datasets. The evidence base would lose a tiebreak against a team reading 2023-2025 intelligence community assessments or NIST technical reports.

### Collapse flexibility
**Kim Zetter, 15, WIRED** — "Security researchers believe they have finally solved the mystery around how a sophisticated backdoor embedded in Juniper firewalls works... the NSA may be responsible for that backdoor, at least indirectly." This provides a distinct, empirically grounded impact scenario (NSA-engineered backdoor hijacked by third parties) separate from the general "backdoors weaken security" claim, allowing the Con to collapse to a specific historical precedent if the generic security argument is mitigated. Similarly, the **Avast, 20** EternalBlue/NSA/WannaCry/NotPetya chain offers a second independent collapse pathway (government stockpiling → leak → global cybercrime).

### Warrant depth
**Avast, 20, What Is EternalBlue...** — The card provides extensive technical warranting: it explains the SMBv1 vulnerability mechanism, the NSA's development and five-year hoarding of the exploit, the Shadow Brokers leak timeline, Microsoft's patching response, and the specific propagation method (maliciously crafted packets → malware spread). It then warrants impact magnitude with named victims (NHS, Maersk, FedEx, Merck) and quantified damages ($4B WannaCry, $10B+ NotPetya). Taglines like "EternalBlue caused billions in global damages" are backed by multi-step causal explanation, not mere assertion.

### Internal consistency
The case maintains uniform framing: every card reinforces "backdoors = systemic vulnerability → exploitation by state/non-state actors → massive economic/human rights harm." No contention undercuts another. However, the document appears to be an unstructured evidence dump rather than a organized case with labeled contentions—the Olsen 2016 text is duplicated verbatim in two separate blocks, and cards from 2015-2025 are interleaved without clear narrative segmentation. This structural inconsistency suggests the doc is a raw evidence compilation, not a finalized case construct.

### Overall construction score
**Score: 4/10** — The case has strong warrant depth on key historical examples (Juniper, EternalBlue) and one effective defensive spike, but lacks embedded weighing, offensive spikes, coherent structure, and sufficiently recent/authoritative evidence across the board, reading more as a research file than a strategically constructed case.
